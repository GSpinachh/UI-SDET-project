# Тест-кейс

## Создание клиента

1. Открыть страницу добавления клиента кнопкой "Add Customer". 
Ожидаемый результат: Открывается форма для добавления нового клиента.
2. Заполнить все поля.
Ожидаемый результат: Все поля заполнены, без ошибок.
3. Нажать кнопку подтверждения "Add Customer".
Ожидаемый результат: Появляется сообщение об успешном добавлении клиента.
4. Закрыть всплывающее уведомление.
Ожидаемый результат: Уведомление закрывается.
5. Проверить, что клиент добавился по выводу окна.
Ожидаемый результат: Появилась информация о новом клиенте.
6. Открыть страницу клиентов кнопкой "Customers".
Ожидаемый результат: Открывается страница со списком клиентов.
7. Получить список имён пользователей.
Ожидаемый результат: Получить новый список имён клиентов.
8. Проверить, что список клиентов отсортирован по алфавиту.
Ожидаемый результат: Список клиентов отсортирован по алфавиту.

## Сортировка клиентов

1. Открыть страницу клиентов кнопкой "Customers".
Ожидаемый результат: Открывается страница со списком клиентов.
2. Нажать кнопку "First Name" для сортировки списка.
Ожидаемый результат: Список клиентов сортируется по имени.
3. Получить список имён клиентов.
Ожидаемый результат: Получить отсортированный список имён клиентов.
4. Проверить, что список клиентов отсортирован по алфавиту.
Ожидаемый результат: Список клиентов отсортирован по алфавиту. 

## Удаление клиента

1. Открыть страницу клиентов кнопкой "Customers".
Ожидаемый результат: Открывается страница со списком клиентов.
2. Получить список имён пользователей.
Ожидаемый результат: Успешно получен новый список имён пользователей.
3. Удалить клиента.
Ожидаемый результат: Клиент удалён из списка.
4. Получить список имён пользователей.
Ожидаемый результат: Получить новый список имён пользователей.
5. Проверить, что клиент удалился из списка.
Ожидаемый результат: Удалённого клиента нет в списке пользователей.
